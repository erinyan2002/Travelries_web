# Travelries 실사용 QA 체크리스트

계정 **A**(나)와 **B**(친구), 두 개로 진행한다. 브라우저 두 개(또는 일반 창 + 시크릿 창)에 각각 로그인한다.
실패한 항목에는 화면 캡처와 함께 **어떤 계정으로 무엇을 눌렀는지** 적는다.

## 0. 준비
- [ ] A, B 모두 Profile에서 이름 설정, 프로필 사진 업로드
- [ ] A가 사진 3장 이상 업로드 (GPS 있는 사진, 얼굴 있는 사진 포함)

## 1. 팔로우 · 피드 (3–4주)
- [ ] A가 Feed 검색에서 B 이름으로 찾기 (`@이름`도 되는지)
- [ ] A → B 팔로우, B → A 팔로우 (팔로잉/팔로워 숫자 반영)
- [ ] A가 게시물 작성 → B의 Feed에 보임
- [ ] B가 좋아요 / 댓글 / 답글 → A에게 알림 (종 아이콘)
- [ ] B가 리포스트 → B의 팔로워 피드에 원작자 이름과 함께 보임
- [ ] A가 게시물 삭제 → 확인 창이 뜨고, 삭제 후 B의 피드에서도 사라짐
- [ ] 아바타/이름 클릭 → `/u/[id]` 프로필로 이동

## 2. 얼굴 ↔ 친구 계정 연결 · 태그 제안
- [ ] A가 Faces에서 B의 얼굴 카드 → **Account** → B 선택 (초록색으로 바뀜)
- [ ] A가 B 얼굴이 있는 사진으로 게시물 작성 → "In this photo: + B" 제안이 뜸
- [ ] 제안을 눌러 태그 후 게시 → B에게 "tagged" 알림
- [ ] **Merge**로 같은 사람 카드 합치기 → 새로고침 후에도 유지

## 3. 공유 · 공개 링크
- [ ] 게시물 **보내기(Send)** → B에게 알림, 알림 클릭 시 게시물로 이동
- [ ] 게시물 **링크 복사** → **로그아웃한 창**에서 `/share/[id]` 열림
- [ ] Albums → Trips → **Share** → **로그아웃한 창**에서 `/trip/[id]`: 지도 경로, 사진, (있다면) 다이어리
- [ ] 공유 링크를 열면 A에게 "share_viewed" 알림

## 4. 공동 앨범 (Collab)
- [ ] A가 앨범 생성 → 초대 코드/링크 복사
- [ ] B가 코드로 참여 → 앨범 페이지가 열림 ("Album not found"가 나오면 안 됨)
- [ ] B가 사진 추가 → A 화면에 보임, A에게 알림
- [ ] 서로 반응(이모지) · 댓글
- [ ] A가 자기 앨범 코드로 다시 참여 → 에러 없이 그 앨범으로 이동
- [ ] 멤버 내보내기 / 나가기 / 앨범 삭제

## 5. 권한(RLS) — "보이면 안 되는 것"이 안 보이는지
- [ ] B가 A를 **언팔로우**한 뒤 A의 게시물 URL(`/post/[id]`)을 열면 → "not available"
- [ ] B가 A의 Albums/Map/Faces를 볼 방법이 없음 (개인 사진은 본인만)
- [ ] 멤버가 아닌 계정 C로 공동 앨범 URL(`/collab/[id]`)을 열면 → 내용이 보이지 않음
- [ ] 로그아웃 상태에서 `/`, `/albums`, `/feed` 접근 → 로그인 화면으로 이동

## 6. AI 기능 (백엔드 실행 중)
- [ ] Trips → **AI Diary**: 수 초 안에 생성, 다시 열면 즉시 표시(캐시)
- [ ] 사진 → **Identify Landmark**: 결과 표시, 다시 열면 재호출 없이 표시
- [ ] 얼굴 여러 명 사진 업로드 → 인원수 맞게 박스, 한 사람이 두 번 잡히지 않음

## 7. 모바일 (5–6주) — 휴대폰 또는 Chrome 개발자도구 → 기기 모드(iPhone SE / 12)
- [ ] 모든 페이지: 가로 스크롤 없음, 알림 종이 버튼을 가리지 않음
- [ ] 하단 메뉴: 좌우로 밀리고, 현재 페이지 탭이 보이는 위치에 있음
- [ ] Feed / Profile / Post / Faces 카드와 버튼이 잘리지 않음
- [ ] 모달(사진 상세, 게시물 작성, 초대)이 화면 안에서 스크롤됨
- [ ] 사진 업로드(카메라/갤러리 선택)가 휴대폰에서 동작

## 8. 테스트 데이터 정리 (7–8주)
- [ ] 테스트용 게시물/댓글/공동 앨범 삭제
- [ ] Albums → **Clean up**으로 중복·흐린 사진 정리
- [ ] 전시회용 데모 계정에는 보여줄 사진만 남기기
